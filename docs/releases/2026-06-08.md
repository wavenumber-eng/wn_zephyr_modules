# Release Notes: 2026-06-08

## `v2026-06-08`

`rt_config` item-count guard release.

- Adds `CONFIG_RT_MAX_ITEMS`, default `64`, so applications with larger setting
  tables can size the rt_config status arrays explicitly.
- Adds default-on `CONFIG_RT_CONFIG_VALIDATE_ITEM_COUNT`, which fails the Zephyr
  post-link build if the linked `RT_CONFIG_ITEM()` count exceeds
  `CONFIG_RT_MAX_ITEMS`.
- Adds a runtime guard in file-backed rt_config initialization so item overflow
  returns `RT_RETURN_FILE_ERROR` instead of writing past the status tables.
- Clears the per-item file status tables before rebuilding them during init.

Validated with FUM PDCM at 70/128 items, FUM PDM at 3/64 items, and a forced
failure threshold check.
