# Release Notes: 2026-06-05

## `v2026-06-05`

`rt_config` file export performance and compatibility release.

- Adds `CONFIG_RT_CONFIG_FILE_EXPORT_COMMENTS`, default `y`, so existing
  applications keep commented exports by default.
- Adds compact `name=value` export when applications set
  `CONFIG_RT_CONFIG_FILE_EXPORT_COMMENTS=n`.
- Adds `CONFIG_RT_CONFIG_FILE_EXPORT_BUFFER_SIZE` for the bounded staging buffer
  used during export.
- Coalesces each exported config item before writing to the filesystem.
- Checks partial `fs_write()` failures and `fs_close()` failures.
- Serializes export with a mutex.
- Adds C++ linkage guards to `rt_config.h`.

Validated against FUM PDCM, FUM PDM, and CricketNode builds. FUM hardware smoke
tests showed compact export reducing PDCM shell save latency from multi-second
behavior to roughly one second on the W25Q128 FAT-backed configuration file.
